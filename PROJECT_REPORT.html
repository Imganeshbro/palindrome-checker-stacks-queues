1. Problem Statement

A palindrome is a string, word, phrase, or number that reads identically forwards and backwards (e.g. "radar", "12321", or "A man, a plan, a canal: Panama").

Objectives:

  • Implement custom Stack (LIFO) and Queue (FIFO) classes from scratch without using high-level string reversal shortcuts.
  • Demonstrate that pushing characters to a Stack reverses their order while enqueuing them to a Queue preserves their order.
  • Build an interactive Graphical User Interface (GUI) visualizing the Stack container, Queue channel, step forward progression, and matching indicators.
  • Derive and empirically measure the Step Count, Time Complexity ($O(N)$), and Space Complexity ($O(N)$).

2. Algorithm

Symmetry Invariant:
Stack LIFO Pop Sequence: ⟨ cn-1, cn-2, ..., c0 ⟩ (Reversed Order)
Queue FIFO Dequeue Sequence: ⟨ c0, c1, ..., cn-1 ⟩ (Original Order)
Equality Condition: ∀ i ∈ [0, n-1], Stack.pop()i == Queue.dequeue()i ⇔ Palindrome 
ALGORITHM PalindromeChecker(input_str):
1.  cleaned_str = filter_and_lowercase(input_str)
2.  n = length(cleaned_str)
3.  IF n == 0 THEN RETURN True
4.  stack = NEW Stack()
5.  queue = NEW Queue()
6.  FOR EACH char IN cleaned_str DO:
7.      stack.push(char)
8.      queue.enqueue(char)
9.  WHILE NOT stack.isEmpty() AND NOT queue.isEmpty() DO:
10.     ch1 = stack.pop()
11.     ch2 = queue.dequeue()
12.     IF ch1 != ch2 THEN:
13.         RETURN False (Mismatch detected)
14. RETURN True (Valid Palindrome)

3. Program (Core Implementation)

Below is the custom data structures and verification engine implementation:

# Data Structures: Custom Stack and Queue Classes
class Stack:
    def __init__(self):
        self._items = []
        self.operation_count = 0

    def push(self, item):
        self._items.append(item)
        self.operation_count += 1

    def pop(self):
        if self.is_empty(): raise IndexError("pop from empty stack")
        self.operation_count += 1
        return self._items.pop()

    def is_empty(self):
        self.operation_count += 1
        return len(self._items) == 0

class Queue:
    def __init__(self):
        self._items = []
        self.operation_count = 0

    def enqueue(self, item):
        self._items.append(item)
        self.operation_count += 1

    def dequeue(self):
        if self.is_empty(): raise IndexError("dequeue from empty queue")
        self.operation_count += 1
        return self._items.pop(0)

    def is_empty(self):
        self.operation_count += 1
        return len(self._items) == 0

class PalindromeChecker:
    def __init__(self, ignore_case=True, ignore_punct=True):
        self.ignore_case = ignore_case
        self.ignore_punct = ignore_punct
        self.stack = Stack()
        self.queue = Queue()

    def check(self, text):
        cleaned = "".join([c.lower() for c in text if c.isalnum()]) if self.ignore_punct else text
        for ch in cleaned:
            self.stack.push(ch)
            self.queue.enqueue(ch)

        comparisons = 0
        while not self.stack.is_empty() and not self.queue.is_empty():
            comparisons += 1
            if self.stack.pop() != self.queue.dequeue():
                return False, comparisons
        return True, comparisons

5. Description of Project

The Palindrome Checker application combines fundamental computer science principles with an interactive graphical interface.

  • Dual-Structure Symmetry: By simultaneously inserting each character into a Stack and Queue, we create two complementary perspectives of the same string: reversed (LIFO) and sequential (FIFO).
  • Interactive Visualizer: Built using Python Tkinter, users can watch characters populate the vertical Stack tube and horizontal Queue conveyor, followed by animated step-by-step popping and dequeuing into the Comparison Pod.
  • Step Controls: Provides Auto-Play with a speed slider, manual Step Forward button for classroom demonstrations, and instant evaluation.

7. Time Complexity, Space Complexity & Step Count

7.1 Step Count Formulation

Let N = raw length, M = cleaned length, and k = comparisons performed:
T(N, M, k) = (3N + 1) [Preprocessing] + 2M [Push & Enqueue] + 5k [Pop, Dequeue & Compare] + 2
Total Step Count Formula: T = 3N + 2M + 5k + 2

8. Conclusion

The implementation confirms that pairing a Stack (LIFO) with a Queue (FIFO) provides an optimal $O(N)$ time and $O(N)$ space algorithm for palindrome detection. The visual interface bridges abstract algorithmic concepts with concrete visual representations, making it ideal for classroom and laboratory evaluation.
